Lecture 4

Notes

1. Lecture Focus

This lecture develops intuition about how Bayesian inference changes under different conditions by studying the interaction between: - data size (small vs large), and - prior strength (weak vs strong).

The goal is to understand how posterior estimates and uncertainty behave in practical modeling.

2. Single-Parameter Inference (Beta–Bernoulli)

2.1 Data Generation

Binary data are generated from a Bernoulli process with true probability: - \( p = 0.7 \)

Two sample sizes are used: - Small sample: size = 10 - Large sample: size = 1000

2.2 Model

  • Likelihood: Bernoulli
  • Parameter inferred: \( p \)
  • Prior: Beta(\(\alpha,\beta\))

Two prior regimes are considered: - Weak prior: low-information Beta prior (e.g., Beta(1, 1)) - Strong prior: concentrated Beta prior (e.g., larger \(\alpha,\beta\))

3. Four Scenarios (Core Results)

3.1 Small Data + Weak Prior

  • Posterior remains wide (high uncertainty).
  • Estimates can vary noticeably due to sampling variability.

Key point: with little data and weak prior information, uncertainty remains high.

3.2 Large Data + Weak Prior

  • Posterior concentrates tightly around plausible values of \( p \).
  • Prior influence becomes negligible.

Key point: with sufficient data, the likelihood dominates even with weak priors.

3.3 Small Data + Strong Prior

  • Posterior is strongly influenced by the prior.
  • Data updates the prior, but only modestly when the sample is small.

Key point: strong priors can dominate inference when data are limited.

3.4 Large Data + Strong Prior

  • Posterior is largely driven by the data.
  • Prior influence diminishes as sample size increases.

Key point: large data typically overrides prior strength.

4. Summary of the Single-Parameter Experiment

  • Data size controls how informative the likelihood is.
  • Prior strength controls how influential prior beliefs are.
  • Increasing data reduces posterior uncertainty and reduces sensitivity to priors.

5. Multiple-Parameter Inference (Location and Scale)

5.1 Setup

Data are generated from a heavy-tailed distribution (Cauchy). A Normal likelihood is used to illustrate multi-parameter inference under modeling assumptions.

5.2 Model

  • Likelihood: Normal
  • Parameters inferred: \( \mu \) and \( \sigma \)

6. Observations in Multi-Parameter Inference

  • Posterior uncertainty is estimated for each parameter.
  • Parameters interact: uncertainty in one can affect the other.
  • More data improves identification of both \( \mu \) and \( \sigma \).
  • Prior assumptions can influence parameters differently.

7. Key Takeaways

  • Bayesian inference provides a distribution over parameters (not only point estimates).
  • Small data leads to higher uncertainty and greater prior sensitivity.
  • Large data leads to tighter posteriors and more data-driven results.
  • The same principles apply to both single-parameter and multi-parameter models.
