Why Do We Need Distributions in Bayesian Modeling?

In Bayesian statistics, we model uncertainty using probability distributions.
Distributions are important because they help us describe:

  1. How uncertain we are about unknown values (parameters)
    Example: What is the probability of heads in a coin? We don’t know the exact value, so we represent it as a distribution.

  2. How the observed data is generated (likelihood)
    Different datasets behave differently:

  3. Binary data (0/1) fits Bernoulli
  4. Count data fits Poisson

  5. Bell-shaped continuous data fits Normal

  6. How our beliefs change after observing data (posterior)
    Bayesian inference updates the prior belief into a posterior belief: $$ Posterior \propto Likelihood \times Prior $$

Quick Summary

  • Prior: distribution before seeing data
  • Likelihood: distribution that explains the observed data
  • Posterior: updated distribution after seeing data

2) Prior Predictive Sampling

Prior predictive sampling generates samples from your model before using any real data.
It helps confirm that your priors produce reasonable outcomes.

Typical workflow

  1. Define priors (and optionally a likelihood without observed data).
  2. Sample from the prior predictive distribution.
  3. Plot the simulated values and check if they match expectations.

3) Quick Visualization Pattern (Plot Any Variable)

Idea

  • Flatten if needed (useful for vector-valued distributions like Multinomial)
  • Plot using ArviZ
