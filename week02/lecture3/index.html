Week 2 — Lesson 1: PyMC Distributions, Prior Predictive, and a Coin Flip Model

Learning Goals

  • Understand common PyMC distributions (discrete and continuous)
  • Learn prior predictive sampling (what the model believes before data)
  • Build a simple Bayesian coin-flip model
  • Visualize distributions using ArviZ

2) Prior Predictive Sampling

Prior predictive sampling generates samples from your model before using real data.
This is used to check if your priors make reasonable predictions.

Typical workflow: 1. Define your priors (and optionally a likelihood with no observed data) 2. Sample from the prior predictive distribution 3. Plot the simulated values to see if they match your expectations

3) Quick Visualization Pattern (Plot Any Variable)

Idea: - Pick a variable name - Extract its samples from idata.prior - Flatten if needed (for vector outputs like Multinomial) - Plot with ArviZ

This makes it easy to explore any distribution with minimal changes.

4) Example Model: Coin Flips (Bernoulli Likelihood)

Data encoding

Convert string outcomes into numbers: - Heads -> 1 - Tails -> 0

Example data: "HHTTHHHTTH"

Model idea

We want to learn the probability of heads p.

  • Prior: [ p \sim Beta(\alpha=1,\ \beta=5) ]
  • Likelihood: [ y_i \sim Bernoulli(p) ]

What we learn

After sampling, the posterior distribution gives: - the most likely value of p - uncertainty in p after seeing the coin flip results

5) Short Example: Bell-Shaped Data (Normal Likelihood)

When your observed data looks approximately bell-shaped around some average value, a Normal likelihood is a good choice.

Model structure

Assume you observe measurements y:

  • Likelihood: [ y_i \sim Normal(\mu,\ \sigma) ]

  • Priors (one reasonable setup): [ \mu \sim Normal(0,\ 10) ] [ \sigma \sim HalfNormal(5) ]

Interpretation

  • mu represents the center of the bell curve (average value)
  • sigma controls how spread out the values are
  • the posterior estimates mu and sigma using the observed data

Key Takeaways

  • Choose distributions based on your data type:
  • discrete (counts/categories) vs continuous (real-valued)
  • Prior predictive sampling helps validate your assumptions early
  • Beta is commonly used as a prior for probabilities
  • Bernoulli likelihood works for 0/1 data (coin flips)
  • Normal likelihood is a standard choice for bell-shaped data
